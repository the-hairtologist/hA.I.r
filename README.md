# hA.I.r

Starter repository for the-hairtologist's hA.I.r project.

This repository contains TypeScript and Dart code and is configured for a modern web app stack.

Tech stack (suggested):
- TypeScript + Vite
- React
- Tailwind CSS
- Supabase (optional) for backend/auth
- Playwright for E2E tests

Getting started
1. Copy .env.example to .env and fill in the VITE_SUPABASE_* variables.
2. npm install
3. npm run dev

Notes
- Do not commit secrets or production keys. Use environment variables or a secret manager.
